# JAMMED
An 8-bit platformer inspired by Jams Player, featuring retro-style gameplay and nostalgic pixel art.

CONTROLS: 
* Move - A, D
* Jump - Spacebar (press again mid-air for the Rocket Axe boost)
* Shoot - Q, N
* Swap Guitar - C
* Guitar Rack - G
* Pause - E
* Stage Select - S (from the title screen)

On touch devices: joystick + jump/shoot buttons, with on-screen
SWAP and RACK buttons in the top-right HUD.

COLLECTIBLES:
* BREAD - five per stage, the end-credits grade you on them
* ANT tokens - one hidden per stage, eight total. An x0x tag
  scratched on a nearby wall brightens when one is close by.
  Find all eight to open the hidden stage.

Leave feedback or suggestions in issues. Enjoy!
